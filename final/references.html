References

This page lists external resources used while developing TAMAGREN Tracker. This page is intentionally left out of the main site navigation and page count, per course convention for attribution pages.

External References

  • MDN Web Docs — HTML. Technical reference for semantic HTML.
  • MDN Web Docs — CSS. Technical reference for responsive CSS, including Grid and media queries.
  • MDN Web Docs — JavaScript. Technical reference for ES Modules, the Fetch API, array methods, and the DOM.
  • MDN Web Docs — Window.localStorage. Technical reference for browser storage.
  • MDN Web Docs — URLSearchParams. Technical reference for reading query parameters on the contact confirmation page.
  • MDN Web Docs — <dialog>. Technical reference for the native modal dialog used in the Activity Library and Timer features.
